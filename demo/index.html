Streams every GC_PAUSE phase step live from bin/luna (LUNA_GC_PAUSE_TRACE_US=1). A 0.000 pause in a rival column is a test_gc/gc_all_results.csv reference value: for Python it means the cyclic collector never fired (refcount reclaims instantly), for binary_trees it means Luna never triggered a collection during the run — the live chart is where those zeros get their context. Rivals refresh whenever you fully re-run make test-gc-all before starting this demo.
