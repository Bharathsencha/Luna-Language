    gc: incremental remembered-set scan bounds mark_roots pauses
    
    Minor-GC mark_roots used to push every remembered-set entry to the gray
    stack in one unbounded pass.  Under churn (e.g. stores into freshly
    promoted containers during incremental sweep) the set can reach tens of
    thousands of entries and mark_roots took 0.3-0.45ms (cycles benchmark).

    Memory Management
    -----------------
    Replaced manual memory handling with a hybrid deterministic system:
      - Reference counting for strings and lists (immediate free at zero refs)
      - AST memory arena using pointer-bump allocation (O(1) cleanup, zero per-node frees)

    ----------------
    Implemented global string interning via a hash set. All identical string identifiers
    now share a single canonical pointer, enabling O(1) pointer-identity comparisons
    instead of strcmp, and unlocking AST lexical caching for near-zero-cost variable
    lookups inside hot loops.
    
    AST Improvements
    ----------------
    AST nodes for ident, assign, inc, and dec now carry an inline lexical cache.
    Loop variables resolve in O(0) after the first iteration. Cache is invalidated
    per-scope via an env version counter, keeping recursive function calls safe.
